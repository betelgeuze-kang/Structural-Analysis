# Teacher action preparation and conditional cost

The original E05 TRAIN diagnosis keeps its fixed 20 negative labels. Fifteen
selected states abstained to secant; five proposed corrections without meeting
the original three-repeat cost criterion. A nonselected teacher's local benefit
is not substituted into that roster. Those original comparisons, labels and
completed numerical stages remain immutable.

`scripts/rc_teacher_action_protocol.py` prepares a separate JSON contract and
annotates supplied observations. It does not fit a policy, run a solver, load
original campaigns or feed the existing gate. The original driver, runtime,
seed policy and label rule are unchanged. The prepared contract is explicitly
**prepared-not-executable**; it is not a numerical launch authorization.

The observation unit is a declared teacher policy and TRAIN state, with three
declared repetitions. Teacher fit index, policy, source sample, native parent,
case, target and exclusion provenance identify that unit. Policy/teacher identity
is needed because different teachers can return different candidates for the
same state. A complete supplied roster stays in the denominator even when a
state, repetition, decision, clock or verification is unavailable.

Availability records the actual returned decision. Ordinary proposals,
abstentions, invalid candidates, guard failures, declined recovery and proposals
after a reference failure remain distinguishable. Missing facts remain unknown.
An abstention is not a measured negative conditional correction value; an
arm-level rejected invocation is not automatically a learned-proposal rejection.

Conditional cost is available only if all three ordinary proposals have verified
comparisons, known native counters and positive exact-integer enclosing arm clocks. Its
worst observed fractional benefit is `min(1 - proposal_wall_ns / secant_wall_ns)`.
Capture, inference, rejected attempts, recovery and step IO remain inside the
supplied proposal-arm clock. Final path writing is outside that clock and needs
separate accounting. Native counter completeness does not establish full assembly
or material work. Nested component clocks are not added to enclosing clocks.
Other cases keep a null value and an explicit reason. This metric neither
relabels original data nor proves chronological full-path benefit.

Future measured report hashes cannot be known before execution. The immutable
protocol can declare pending report slots, while a separate completion mapping
binds actual report hashes to the same teacher/state/repetition afterward. The
protocol is not rewritten with observed hashes. Supplied completion consistency
does not authenticate a producer, operator or hardware. Declared connected TRAIN
exclusions are also not an independent leakage audit.

Before a numerical campaign, separately freeze its physical family, source and
teacher artifacts, connected project/geometry/load-history exclusions, actor
assignment, resource limits, arm order and repetitions. Instrument actual action
decisions and full native/assembly/material costs. Retain unknown work and failed
or unavailable states. Each evaluation arm must use its own chronological native
predecessor; reference-parent singleton probes cannot replace that comparison.
Measure offline generation/fitting/selection, online feature/gate/inference,
native recovery, persistence and whole-job time, memory and disk in separate
nonoverlapping scopes. Reserved validation and development holdout must not be
used to select teachers, tune thresholds or repair labels.

The current authored connected groups do not establish independent physical
projects. Independent experimental matching, rights, owner/operator and hardware
conditions remain open. Pure contract tests and preparation outputs carry zero
new scientific solve or fit credit. Publication of this helper, a green test, or
an observed singleton benefit does not qualify AI gain or service readiness.
