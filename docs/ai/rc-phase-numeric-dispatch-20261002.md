# Isolated RC phase numerical dispatch

The isolated RC phase supervisor forwards a bounded `OPENBLAS_CORETYPE`
identifier alongside its existing numerical thread limits. An authored parent
dispatch pin, such as the repository CI's `Haswell`, therefore reaches fresh
analysis and verification interpreters. Authentication, loader injection and
arbitrary import configuration remain excluded from the child environment.

The trigger was c594's PR450 Python shard3 job110624020433, which reported four
failures in the original native-state equality regression. Its producer
b0a48b6e9aecd845c762a476d18d5b104dc16da6 has the same tracked tree as c594.
The job log pins Haswell and one thread; the previous child environment omitted
the CPU dispatch pin. Three displayed native projections have changed numeric
state and dependent hashes. The constant-v2 projection has unchanged terminal
checkpoint bytes and three changed step/artifact hashes; the log does not expose
the exact differing step payload or identify which isolated arm failed.

Unmodified c594 passed the same four Haswell cases on the local host. This does
not resolve the hosted failure or establish equivalence between hosts. A separate
local Nehalem proportional-v1 counterexample failed the original byte equality
comparison when the parent dispatch pin was omitted from fresh children.

This change preserves the existing exact native checkpoint, response and step
comparisons. It does not round, clip or replace solver output, change tolerances,
alter solver profiles or reinterpret completed research labels. Dispatch names
are bounded ASCII identifiers, not a claim that every identifier denotes a
supported CPU on every installation.

Focused lifecycle/environment and native regression results belong to their
exact local source and numerical runtime. They are software verification, not
independent physical validation, research campaign results, performance proof or
release approval. Current hosted CI continues on its original c594 source;
later commits require their own CI results.
