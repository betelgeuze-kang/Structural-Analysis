# Prespecified v6 full-path residual observation campaign

This campaign diagnoses learned initial residuals on each proposal arm's actual accepted history. The earlier same-parent cross-arm audit retained only 11 unique early case/target pairs. Here each eligible proposal is observed together with secant on its own accepted parent before the unchanged proposed seed is solved. Lower residual is not assumed to imply lower total cost; no residual-based selection gate is introduced.

The campaign reuses the pinned 99+66 development labels, all five connected training groups and all 15 development cases. It uses the existing constant-safe SVD profile, ridge values 10,000 and 1,000,000, group exclusion, static model abstention and secant fallback. Each complementary fit has 132 samples; all preprocessing is refitted only on those samples. Repetitions use the existing three counterbalanced arm orders, producing 90 comparisons and 360 full paths including fresh references. Reserved validation/holdout cases remain unexecuted. This is internal development evidence, not independent project evaluation.

The driver declares at most 31 selection fits, one separate metadata fit, 6,840 nonlinear core calls and 1,980 additional observation assemblies (90 comparisons times at most 11 eligible targets times two seeds). Failed/abstained proposals are not silently discarded. Actual observation counts may be smaller. Every full path retains the existing tolerance and full-history checks. Observation errors make a path incomplete and remove performance credit. No production policy is automatically promoted.

Full path wall times include observations and their persistence. The observer reports full residual/tangent assembly, not a cheap residual-only calculation. Its invocation time and assembly attempts are separated from Newton invocation work. Historical label-generation cost and new fitting cost remain separately reported. The measured ratio describes the instrumented policy; it is not an estimate of uninstrumented performance, and comparisons with older revisions are not causal speedup evidence.

Before execution, export the exact committed source to a fresh packet, preserve a source manifest, run input preflight, and execute without another local numerical campaign. Retain all outputs, including failure records. On completion, audit policy/label exclusions, unchanged tolerances, request/model/source identities, complete roster, original residual-observation parent and seed bindings, all additional work and repeat scores. Create and reread the packet inventory. No aggregate empirical conclusion is available until that work finishes.

The run is invoked with `run_rc_pooled_runtime_campaign.py --fit-solver svd-ridge-exact-constant-centering.v1 --observe-initial-residuals` plus the two pinned label roots, exact source revision and fresh output directory. An independent audit uses `audit_rc_pooled_runtime_campaign.py` on that frozen source. This protocol does not close the independent physics, licensing, broader materials/3D, operator or release requirements.

Implementation validation: all 74 runtime-selection tests pass (163.67 seconds); the observer, runtime-cost and workflow-contract suites pass 172 tests (10.78 seconds). The latter includes actual report auditing and rejection of a substituted observation parent. Ruff and whitespace checks pass. An initial focused test found that the selection result omitted the opted-in observation flag; the result now preserves it as well as the plan. These checks do not replace the planned empirical campaign.
