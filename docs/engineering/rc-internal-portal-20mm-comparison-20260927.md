# Internal 20 mm portal comparison: exact-source observations

This record covers the original two-base, three-member 4 m by 3 m portal at the 20 mm request only. It is an **internal software observation**, not an admission of the original public formulation or an independent physical validation. The preserved original model and request SHA-256 values are `6f8eec155f5fcf2f9ae942c021a8692e79ae1efd0d1b98342f8aea0b642d0ed6` and `e0cbc4995e2c98f4a30a0902ac321b4a0e66a9baa61ed20a88e5e73809df627e`. The runner changed only the three member formulation tags to the internal corotational element, bound constant N3 UY and N4 UY loads of -25 kN each, retained the N4 FX +150 kN reference load, and controlled N4 UX through -10, -20, and +10 mm. Every three-target arm path began at a fresh genesis checkpoint and repeated a one-step `λ=0` constant preload; it did not reuse a mutable checkpoint from another arm. The original request specified terminal polishing, which the internal direct-control solver does not provide. The internal preload used the unpolished load solver.

The 20 mm condition comprises two repetitions of fixed and adaptive modes, four arms in each comparison, and 16 paths total. Both the mode order and four-arm order reverse on the second repetition. `reference` and `fresh_reference` use no seed; `secant` uses the deterministic extrapolation `q_last + (target - t_last) × (q_last - q_previous) / (t_last - t_previous)` with the control coordinate set to the target. `frozen_parent_recovery` starts with ordinary direct control and, only on failure, would use coordinate-only continuation trials against the unchanged material parent. Fixed mode allows 16 stages; adaptive mode allows up to 64 trials with bounded increment adjustment. No continuation was exercised in the completed run. There is no trained proposal policy here. Compared with the original 48-path design, this record excludes 40/80 mm, changes the element formulation, omits terminal polishing, and substitutes deterministic frozen-parent recovery for an unavailable learned arm.
