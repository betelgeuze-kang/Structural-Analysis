# Multimember L-frame continuation breadth and cost protocol

Start from `examples/public_rc_fiber_frame_l_frame_material_history.json`, preserving its two RC members, materials, section, integration order, supports and proportional FY=-150 kN reference load at N3. Use two declared geometries: horizontal/vertical lengths (2.0,1.5) m and (3.0,2.5) m. Both have six free physical coordinates. Control N3 UY (global DOF 7); this is an in-plane tip-displacement test, not a lateral-building or 3D claim.

Add the same synthetic constant N3 FY=-25 kN preload in each case. Use three new coarse requested target sequences: (-1,-2,+1), (-10,-20,+10), and (-20,-40,+20) mm. These are not the separate published fine-grid cyclic request. Use original default native tolerances/configuration, permit two reversals including the loaded origin and retain every preload/prefix/reversal failure. Do not adapt amplitudes, preload, tolerances or candidate modes after observing results.

For each of the six geometry/history combinations, compare upfront frozen-parent continuation and failure-only continuation in two balanced mode/arm orders, each followed by fresh ordinary reference: 24 comparisons / 96 attempted paths. Retain complete original artifacts, additional numerical work and unknown-work indicators. Pair proposal histories with existing 1e-10 absolute / 1e-8 relative comparison limits; incomplete pairs receive no time ratio. Report partial completion, different roots and reference failures without excluding cases.

This extends internal numerical testing from one member to a turned two-member topology. Geometries are public synthetic model variants, not independent projects, external experiments or newly admitted training data. No learned fit or protected-case evaluation receipt is produced. Freeze the committed source before executing; preserve all source/input identities and costs. Independent physical validation, corotational/3D/sparse qualification and product approval remain separate.
