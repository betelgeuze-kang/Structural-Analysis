# Opt-in complete-path trust-region reversal strategy

`benchmark_rc_control_seed_paths(..., trust_region_reversal=True)` runs a fixed parent-start SciPy TRF proposal only at an accepted direction reversal. The numerical proposal has no commit authority. Original Newton checks every returned coordinate vector, regardless of optimizer termination, and preserves rejected proposals and the existing single reference fallback. Unknown optimization work stops the proposal path before another core invocation. Normal benchmark defaults are unchanged.

The proposal report records SciPy version, parent, target, termination, candidate, residual, every actual function/Jacobian assembly callback and elapsed time. Proposal time is inside enclosing path time. Optimizer assemblies are separate from Newton assembly sidecars. Retained-coordinate and conflicting caller strategies are rejected before output. The native parent remains byte-identical throughout optimization.
