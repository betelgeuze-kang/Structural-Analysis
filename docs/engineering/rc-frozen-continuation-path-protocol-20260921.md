# Full-path frozen-parent proposal protocol

The opt-in `frozen_parent_continuation=True` benchmark strategy triggers only at an accepted direction reversal. It uses sixteen evenly spaced internal targets with one fixed native material parent, retaining each original stage artifact and assembly sidecar. Only coordinates carry across stages; intermediate checkpoint states are not adopted. The outer original-target Newton invocation remains responsible for the accepted path step. Ordinary defaults and tolerances are unchanged.

Known unsuccessful stages abstain to the ordinary start with all work retained. An interrupted/unknown stage stops the proposal path and sets both additional-work and overall-work flags unknown. The report separately sums attempted native proposal calls, known Newton/linear work and optimizer callback counts, because existing outer invocation counters alone are not full cost. Proposal wall time includes stage serialization and lies inside whole path time. Configuration conflicts reject before output.
