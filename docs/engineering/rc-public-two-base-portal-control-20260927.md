# Two-base RC portal direct control: bounded public integration

The experimental direct-control API now admits a connected serial RC chain with **two distinct fully fixed endpoints** when `experimental_two_fixed_endpoints=true` is supplied. This is a separate, small-displacement fixed-chord compiler profile. The ordinary public load-control profile and unmarked direct-control requests continue to require one fixed endpoint. The two-base result includes all six support reactions, and the request/profile binding is checked by fresh-source artifact validation and restart replay.

The [preserved original model](../../examples/research/rc_internal_portal_20mm/original-model.json) is unchanged (SHA-256 `6f8eec155f5fcf2f9ae942c021a8692e79ae1efd0d1b98342f8aea0b642d0ed6`). The [preserved original request](../../examples/research/rc_internal_portal_20mm/original-request.json) is unchanged (SHA-256 `e0cbc4995e2c98f4a30a0902ac321b4a0e66a9baa61ed20a88e5e73809df627e`). The [derived v3 request](../../examples/research/rc_internal_portal_20mm/experimental-two-fixed-endpoints-request.json) adds only the explicit opt-in through typed request serialization (SHA-256 `92e94d3580bdf76edabef458ac0f769e054087ab04f897178f3692b2098c0e45`). It retains both −25 kN roof loads, +150 kN N4 horizontal reference loading, the original solver settings including terminal polishing, and displacement targets −10, −20, +10 mm. These are one authored portal and one loading history, not independent structures.

The full original target sequence returned `ready`, accepted all three targets, and passed a separate complete fresh-source validation. The focused public integration regression checks both support reaction sets, horizontal and vertical force balance at every accepted target, the v3 request binding, and the CLI's own execution plus replay. These observations establish that this **fixed-chord software path** can now execute the authored portal input. They do not validate its physical response against a laboratory specimen, make it equivalent to the separate internal corotational portal, or approve design use.

A read-only comparison with the preserved internal corotational 20 mm reference path found identical controlled N4 displacements but distinct responses. At −10, −20, and +10 mm, the absolute load-factor differences were 0.005795, 0.017143, and 0.005197; the largest support-force component differences were 0.988, 2.815, and 0.822 kN, respectively. The preload responses agreed to numerical precision. These are different element formulations, and the public path also uses the original request's terminal polishing while the internal preflight did not polish its preload. The differences are **not measured physical errors** or a ranking of formulation accuracy.
