# SND RC beam data: metadata and byte-access check

This is a source-access audit, not an admitted measurement set or a physical validation. It is separate from the [Mathern–Yang conventional RC reference-beam source record](../../benchmarks/rc_fiber/mathern_yang_2021_reference_source.v1.json).

The primary [SND dataset record](https://researchdata.se/en/catalogue/dataset/2021-291-1), DOI [`10.5878/rnn3-dy47`](https://doi.org/10.5878/rnn3-dy47), describes a stainless-steel reinforced concrete beam in four-point bending, with service-load cycles followed by cycling to failure. Its public metadata lists actuator and DIC deflection data, `BD_data.txt`, `paper_data.mat`, a `read_me.txt`, and setup figures. It labels access as open and the dataset license as [Open Data Commons PDDL 1.0](https://opendatacommons.org/licenses/pddl/1-0/). These are **metadata claims**, not proof that the published data bytes can presently be retrieved or interpreted.

On 2026-09-29, direct GETs to the record's official API download links returned **HTTP 404 with zero response bytes** for each of the following: [BD_data.txt](https://api.researchdata.se/dataset/2021-291-1/1/file/data?filePath=BD_data.txt), [paper_data.mat](https://api.researchdata.se/dataset/2021-291-1/1/file/data?filePath=paper_data.mat), [read_me.txt](https://api.researchdata.se/dataset/2021-291-1/1/file/documentation?filePath=read_me.txt), and [Figure1b.pdf](https://api.researchdata.se/dataset/2021-291-1/1/file/documentation?filePath=Figure1b.pdf). A direct request to the underlying `doris.snd.se` Figure1b endpoint returned HTTP 401. The [SND metadata PDF](https://snd.se/en/catalogue/dataset/2021-291-1/1/export/pdf) still lists the file names and sizes; it does not provide a verified checksum or the file contents.

No source file hash, channel/units audit, complete geometry crosswalk, ordered numeric response, or source-to-solver comparison can be asserted from that metadata. Current admitted measured evaluation rows: **0**. Current admitted training rows: **0**. Recheck the actual publisher files if their download service becomes available; do not replace them with catalog snippets, a paper plot, or another beam's data.
