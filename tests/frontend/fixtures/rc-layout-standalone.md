# Original standalone layout graph fixtures

`rc-layout-standalone.json.gz` contains four maps of base64-encoded original
artifact bytes: price/learned order, budgets 2 and 3, first execution order. The
source is the sealed `structural-layout-standalone-http-k2szhu8w/export` packet
(inventory SHA-256 `6bfbec705085bc7b964d6acd2ec22266a8443d92bcb425604940b5d13fcbdca9`).
Each input was checked against that inventory before packing. Gzip decoding and
base64 preserve the original JSON numeric spelling and hashes.

The graphs were generated by source `596e058f167e8663f62e3bc3e8c6ab0bff18807a`,
then admitted and delivered by `6512d5090943033aa29ab406bcb25ce8608a7e99`.
Budget 2 retains price no-selection and learned `large`; budget 3 selects `middle`
in both strategies. No standalone graph ran a later oracle. Prices are synthetic,
geometry/history cases were known, and physical equivalence, independent physical
validation and learned net benefit are not established. This is regression data,
not a new fit, numerical experiment, or measured external dataset.
